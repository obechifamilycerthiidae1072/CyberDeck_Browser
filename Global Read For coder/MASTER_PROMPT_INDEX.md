# CyberDeck Browser Prompt Pack

This pack contains staged prompts for building a native C++20 Windows 11 browser using CEF for Chromium browsing and OpenGL for a real 3D cyberpunk bookmark system called Deck Space.

Recommended usage:
1. Give `00_GLOBAL_RULES_READ_FIRST.md` to the coding AI first.
2. Then feed prompts in numeric order.
3. Do not skip verification at the end of each stage.
4. Do not let the coder jump ahead into flashy 3D before the browser foundation works.
