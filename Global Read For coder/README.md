# CyberDeck Browser Prompt Pack

A staged prompt pack for instructing an AI coding agent to build **CyberDeck Browser**:

- Native C++20 Windows 11 desktop app
- Chromium browsing through CEF
- Real OpenGL 3D bookmark world called **Deck Space**
- Retro 80s terminal/cyberpunk visual identity
- Local JSON storage for history, settings, and bookmark Nodes
- Windows installer target

## How to use

1. Start with `00_GLOBAL_RULES_READ_FIRST.md`.
2. Feed the coding AI prompt files in numeric order.
3. Require build/run verification after each stage.
4. Do not allow the coder to skip licensing, security, or packaging.
5. Use `ALL_PROMPTS_COMBINED.md` only as a reference or bulk import.

## Product naming

- App: CyberDeck Browser
- Bookmarks: Nodes
- Bookmark view: Deck Space
- Add bookmark: Add Node

## Important warning

A browser is a serious commercial app. These prompts are designed to create a strong v1 foundation, but selling it still requires testing, license review, installer testing, and likely code signing.
